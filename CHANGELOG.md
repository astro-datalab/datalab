# Change Log

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [Unreleased]

### Added

- Added `CHANGELOG.md` to begin documenting changes to the Astro Data Lab client.

### Changed

- Added support for Python 3.12, 3.13 and 3.14
- Dropped support for Python 3.9 and Python 3.10
- Dropped support for Astropy v5.x
- Dropped support for Numpy v1.x
- Removed various legacy code and directories
- `specClient` was deprecated in favor of [SPARCL](https://gitlab.com/nsf-noirlab/csdc/datalab/sparcl/sparclclient)
- `dl.helpers.legacy` was deprecated

### Fixed

- Cleaned up various Python files
